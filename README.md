# MyTgBot

Исторический незавершённый Telegram-проект: автоматизация предыдущей работы и портфольная попытка. По текущему статусу владельца приложение не работает и не поддерживается.

## Состав

- `TelegramBot/` — отдельная реализация проекта.
- `TgBot2000.cpp` — другая реализация/эксперимент.

Это сохранённая история разработки, не готовый к запуску продукт. Перед возможным восстановлением потребуется определить поддерживаемую реализацию, зависимости и безопасную конфигурацию. Сборочные каталоги не являются исходниками и не должны храниться в Git.
